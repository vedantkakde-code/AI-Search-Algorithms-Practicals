# AI Search Algorithms & Game Practicals

This repository contains solutions to 3 practical assignments:

1. **Assignment 1: Breadth-First Search (BFS)**  
   Traverses a given graph level by level using a queue.

2. **Assignment 2: A* Search Algorithm**  
   Finds the shortest path from a start node to a goal node using a heuristic (informed search).

3. **Assignment 3: Tic-Tac-Toe Game**  
   A classic 2-player console-based Tic-Tac-Toe game with win/draw detection.
